### Примеры использования
```bash
# Добавить проект
qwen_time_tracker.exe add-project "MyProject" "C:\Projects\MyProject"

# Список проектов
qwen_time_tracker.exe list-projects

# Активировать проект
qwen_time_tracker.exe activate-project "MyProject"

# Добавить задачу
qwen_time_tracker.exe add-task "Fix bug #123" --estimate 01:30 --project "MyProject" --description "Critical bug"

# Запустить таймер
qwen_time_tracker.exe start-timer "Fix bug #123"
qwen_time_tracker.exe start-timer 5  # по ID

# Остановить таймер
qwen_time_tracker.exe stop-timer "Fix bug #123"

# Список задач
qwen_time_tracker.exe list-tasks --status active
qwen_time_tracker.exe list-tasks --status all

# Удалить задачу
qwen_time_tracker.exe delete-task "Fix bug #123"

# Рабочий день
qwen_time_tracker.exe start-day
qwen_time_tracker.exe stop-day

# Статус
qwen_time_tracker.exe status

# Экспорт в Excel
qwen_time_tracker.exe export-excel --from 2026-03-01 --to 2026-03-03 --output "C:\Reports\report.xlsx"
```

## ✅ Этап 7: IPC между CLI и GUI (СИНХРОНИЗАЦИЯ) (ЗАВЕРШЕНО)

### Проблема
При запуске CLI команд, когда приложение уже запущено:
- CLI записывает данные в ObjectBox
- GUI не знает об изменениях
- UI не обновляется

### Решение
Реализован IPC механизм на базе **TCP Socket** (localhost:49172):
- [x] Создан `ipc_service.dart` для обработки сообщений
- [x] GUI запускает IPC сервер при старте
- [x] CLI отправляет уведомления через IPC клиент
- [x] GUI обновляет UI при получении сообщений

### Типы IPC сообщений
```
TASK_ADDED:<id>
TASK_DELETED:<id>
TASK_STARTED:<id>
TASK_STOPPED:<id>
DAY_STARTED
DAY_STOPPED
PROJECT_ACTIVATED:<id>
```

### Файлы для изменения
```
lib/services/ipc_service.dart    ✅ Создан
lib/main.dart                    ✅ IPC сервер запущен
lib/app.dart                     ✅ IPC listener добавлен
lib/services/cli_service.dart    ✅ IPC отправка добавлена
```

### Критерии приёмки
- [x] CLI команды обновляют GUI в реальном времени
- [x] Нет конфликтов данных
- [x] Работает при нескольких экземплярах CLI
- [x] Graceful shutdown при закрытии GUI
