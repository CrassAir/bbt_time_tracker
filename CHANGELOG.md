# Changelog

Все изменения в проекте Qwen Time Tracker.

## [1.0.0] - 2026-03-03

### Добавлено
- ✅ **Объединение проектов** — bbt_time_tracker + remote_qwen
- ✅ **ObjectBox база данных** — хранение таймеров, рабочих дней, проектов
- ✅ **Глобальный таймер** — обновление UI каждую секунду
- ✅ **Круговой прогресс дня** — визуализация 8-часового рабочего дня
- ✅ **Прогресс-бары задач** — процент выполнения для каждого таймера
- ✅ **Свободное/Превышенное время** — расчёт разницы между планом и фактом
- ✅ **Telegram бот** — управление приложением из Telegram
- ✅ **Qwen CLI интеграция** — запуск сессий Qwen
- ✅ **Excel экспорт** — выгрузка отчёта в Excel
- ✅ **Системный трей** — работа в фоновом режиме
- ✅ **Аудио уведомления** — звук начала/окончания дня
- ✅ **Авто-старт дня** — в 11:00 ежедневно
- ✅ **Иконка приложения** — для Windows и macOS

### Изменения
- 🔄 **Timer.durationLeft** — теперь это прошедшее время (увеличивается)
- 🔄 **_spentSeconds** — для завершённых берётся estimate, для активных durationLeft
- 🔄 **WorkDay.createToDate** — хранит текущий день (а не следующий)
- 🔄 **resumeWorkDay** — не сбрасывает startWorkDateTime

### Исправления
- 🐛 **MultiLevelCircularProgress** — таймер обновляется каждую секунду
- 🐛 **GlobalTimer.dayListener** — не удаляется при остановке дня
- 🐛 **ObjectBox сохранение** — таймеры сохраняются каждые 10 секунд
- 🐛 **AudioPlayer** — используется один экземпляр вместо множества
- 🐛 **Free time расчёт** — правильно считает разницу

### Технические детали
- Flutter SDK >= 3.8.0
- objectbox: ^5.2.0
- televerse: ^3.2.0
- audioplayers: ^6.5.1
- window_manager: ^0.5.1
